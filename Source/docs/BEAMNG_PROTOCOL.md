# BeamNG wire protocol

The current mod/Bridge telemetry generation is **43**. It was introduced with V1.41 and is used by the supported V1.43+ release line. Earlier gameplay generations 41 and 42 and their migration-only decoding paths are not supported in the new Bridge.

A project release number can change without modifying its wire protocol. The Bridge checks both wire compatibility and the mod/Bridge release versions and guides the user to `UPDATE_DUALSENSE.exe` if the versions do not match.

**Updater:** V1.43 and later use the unified `UPDATE_DUALSENSE.exe`, which selects the most recent complete stable GitHub Release containing both mod and Bridge ZIPs. The Bridge is updated after verification, while the mod ZIP is staged for manual installation.

**Compatibility JSON:** generated by CI from the current build version and protocol (43), without querying the latest published release. It is an output artifact for the user to put at repository root; CI never pushes it or creates a GitHub Release.
